# Aron.MaplestoryArtale - 楓之谷 Artale 遊戲輔助系統

專為 MapleStory Artale 設計的遊戲輔助工具。以 Windows 原生擷取 API 取得遊戲畫面，透過 AI 影像辨識（視覺模型、OCR、小地圖定位）理解畫面，再以驅動層模擬按鍵完成自動化；**不讀取、不修改遊戲記憶體**。

> 🎉 **目前開放公測！** 以 Google 帳號註冊即送 **6000 點 AI 練功點數（約 500 小時）**。

> ⚠️ **目前沒有解測謊／解輪機制，也不會提醒。** 掛機時請自己留意畫面，出現測謊或輪（輪盤）需要自行處理，詳見[注意事項](#-注意事項)。

**[📥 下載最新版本（1.0.0-beta.9）](https://filedn.com/lClu5LN8zn8Jlro682DsiLh/MapleStoryAI/MapleArtale-1.0.0-beta.9-win-x64.zip)**

## ✨ 功能說明

### 1. 自動 HP/MP 恢復
- **自訂觸發百分比與按鍵**：低於設定值自動按下對應按鍵
- **靈敏度調整**：避免畫面波動造成誤判
- **比寵物更快**：適合邊做別的事邊掛機

### 2. 自動按鍵與防卡鍵
- **分組設定**：每組可獨立啟用、命名（如「祈禱」「聖靈」）
- **隨機間隔**：設定最小／最大間隔，模擬人工操作
- **防卡鍵**：累計一定次數後自動按方向鍵

### 3. 自動跑自由
- 自動按鍵等待期間自動進入自由市場，有按鍵要執行時再自動離開
- 進出都會確認是否成功，失敗會處理而不是卡住

### 4. 角色狀態與練功統計
- HP、MP、EXP 百分比與等級即時顯示
- 經驗效率：1／5／10／30／60 分鐘內的經驗值獲得
- HP／MP 恢復次數統計，可隨時重置

### 5. 地圖辨識與小地圖定位
- 讀取地圖標題自動辨識所在地圖；辨識不出來時可手動選圖，之後會記住
- 從小地圖算出角色在地圖中的位置，作為 AI 練功與計程車的基礎

### 6. 地圖資訊查詢（「地圖」頁）
- **地圖查詢**：小地圖、怪物（等級、數量、重生）、NPC、各出口通往哪裡、是否為城鎮
- **怪物查詢**：等級、HP、EXP、出現地圖、掉寶清單（可反查「哪些怪會掉某物品」）
- **NPC 查詢**：所在地圖與位置
- **路線指引**：從目前地圖到目標地圖、換圖次數最少的走法
- **世界地圖**：標示目前位置，點地點即可查看該區地圖
- **即時定位圖**：在小地圖上顯示角色位置，點 NPC、傳送點、生怪點可看資訊

> 掉寶資料來自遊戲資料的怪物圖鑑，只有物品清單、沒有機率與數量；部分 NPC 位置可能與 Artale 實際不同。

### 7. AI 單圖練功（公測，使用點數）
- 自動辨識怪物與自身角色、選擇目標、移動、施放技能、撿物
- 依地圖平台資料導航（走路、跳躍、爬繩梯、上下平台）
- 角色死亡、畫面異常、點數不足等情況會安全停止並放開所有按鍵

### 8. 自動計程車（公測）
- 在地圖頁選目的地，自動依傳送點規劃路線並逐圖移動
- 換圖後會確認抵達的地圖，走錯會重新規劃

## ⚠️ 注意事項

### 測謊／輪需要自己處理
- **目前沒有自動解測謊、解輪的功能**，出現時必須由玩家自己解。
- **目前也不會偵測或提醒**：出現測謊或輪時，自動按鍵、AI 練功等功能不會自動停止，也不會發出通知。
- 使用自動功能時請留在電腦前或定時查看遊戲畫面，避免因未作答而被系統處置；因此造成的帳號處分請自行承擔（見[免責聲明](#免責聲明)）。

## 🔒 地圖資訊查詢限制

地圖資訊查詢免費，但為避免資料被大量抓取，有以下限制（每個帳號計算，每天以台灣時間 00:00 換日）：

### 查詢（地圖、怪物、NPC、掉寶、路線）

| 限制 | 上限 |
|------|------|
| 需要登入 | 是 |
| 每分鐘查詢次數 | 60 次 |
| 每天查詢次數 | 3000 次 |
| 搜尋關鍵字長度 | 至少 2 個字 |
| 單次結果 | 有筆數上限，以分頁顯示 |
| 整批匯出 | 不提供 |

超過每分鐘上限會顯示「查詢太頻繁，請稍後再試」；超過每天上限需等隔天再查。

### 地圖資料下載（小地圖底圖與定位用資料）

| 限制 | 上限 |
|------|------|
| 每分鐘下載 | 30 張 |
| 每天下載 | 300 張**不同**地圖（同一張重複下載不重複計算） |
| AI 練功中 | 練功付費時間內下載的地圖**不計入**每天上限（每分鐘上限仍適用） |

- 下載過的地圖會存在本機快取，之後進同一張地圖不需要再下載，正常遊玩很難碰到上限。
- 超過上限時程式會暫停下載、稍後自動重試；開始 AI 練功後立即恢復。
- 上限可能依公測狀況調整，以程式內顯示為準。

## 📋 系統需求

| 項目 | 需求 |
|------|------|
| 作業系統 | Windows 10 版本 2004（Build 19041）以上、64 位元 |
| .NET Runtime | 不需另外安裝（程式已內建） |
| 權限 | 需以系統管理員身分執行 |
| 按鍵驅動 | 需安裝 Interception 驅動（首次啟動時引導安裝，裝完需重新開機） |
| 核心隔離 | **必須關閉**「Windows 安全性 → 裝置安全性 → 核心隔離 → 記憶體完整性」，否則按鍵驅動無法載入 |
| 網路 | 需要連線登入與下載地圖資料；HP/MP 等本機功能斷線時仍可使用 |
| GPU（選用） | NVIDIA 顯示卡可用 CUDA 加速；Intel 可選 OpenVINO；也可只用 CPU |

> ⚠️ 本程式使用 Windows.Graphics.Capture API，僅支援 Windows 10 版本 2004（Build 19041）以上。

## 🚀 安裝與使用

### 首次安裝
1. 下載 [MapleArtale-1.0.0-beta.9-win-x64.zip](https://filedn.com/lClu5LN8zn8Jlro682DsiLh/MapleStoryAI/MapleArtale-1.0.0-beta.9-win-x64.zip)（各版本說明見 [Releases](https://github.com/aron-666/Aron.MaplestoryArtale/releases)；**不要**下載 Release 頁面的「Source code」，那不是程式）
2. 解壓整個資料夾到自己的位置（例如 `D:\MapleArtale`），**不要**放在 `Program Files`
3. **以系統管理員身分**執行 `MapleArtale.exe`
4. 首次使用依提示安裝 Interception 按鍵驅動，安裝後**重新開機**
   - **必須先關閉「核心隔離 → 記憶體完整性」並重新開機**，Interception 驅動與記憶體完整性不相容，開著時驅動無法載入；程式偵測到開著時會說明並開啟設定頁
   - 關閉記憶體完整性會降低 Windows 的部分系統防護，請自行評估後再安裝
   - 驅動安裝後，記憶體完整性會無法再開啟（Windows 會列出不相容的驅動程式），要恢復需先解除安裝驅動
5. 程式會自動開啟本機網頁介面；點「登入」以 Google 帳號完成註冊，即可領取 6000 點

### 自動更新
之後的新版本由啟動器自動下載、驗證並更新，不需要再手動下載。設定與登入資料存在 `%LOCALAPPDATA%\Aron.MaplestoryArtale`，更新或重新解壓都不會遺失。

### GPU 加速（選用）
在本機網頁「設定」頁選擇偵測裝置（CUDA／OpenVINO／CPU）。使用 CUDA 時，設定頁可直接下載或修復所需的 CUDA 元件；若要手動安裝，請見 [CUDA 安裝說明](CUDA_INSTALL.md)。

### 疑難排解
- 啟動有問題：查看 `logs\` 資料夾中的 `launcher-*.log`
- 程式檔案損壞：執行 `MapleArtale.exe --repair` 重新下載修復
- 回報問題時：可在「設定」頁開啟診斷模式並匯出診斷包

## 🔧 技術架構

本程式採用 **非侵入式** 影像辨識技術，不直接讀取遊戲記憶體：

1. **Windows 原生擷取**：Windows.Graphics.Capture API＋Direct3D11 擷取遊戲視窗畫面
2. **AI 偵測**：視覺模型（CUDA／OpenVINO／CPU）辨識角色、怪物、傳送點、狀態條
3. **OCR 與小地圖定位**：辨識地圖名稱與數值，從小地圖計算角色在地圖中的座標
4. **地圖平台資料**：伺服器依遊戲地圖資料建立平台、繩梯、傳送點，規劃移動與換圖路線
5. **驅動層按鍵**：透過 Interception 驅動送出按鍵；所有停止與例外狀況都會放開按鍵
